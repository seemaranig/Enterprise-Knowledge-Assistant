# Enterprise Knowledge Assistant

An end-to-end GenAI RAG application built using:

- FastAPI
- Streamlit
- LangChain
- Ollama
- FAISS
- HuggingFace Embeddings

## Features

- PDF Upload
- RAG Pipeline
- Local LLM
- Semantic Search
- AI Chat
- Source Citations
- Completely Free
